## 요구사항 해석

2026-09-29 추가 디자인 요청은 아래 U 단계를 먼저 작성한 뒤 기존 React 프로젝트에 반영했습니다. 상세 범위는 `DESIGN_UPDATE.md`, 상태는 `PROGRESS.md`를 따릅니다.

| 추가 단계 | 작업 | 완료 기준 |
|---|---|---|
| U1 | 제공한 군학연계 폴더 분석 | React·CSS·명세·사진에서 디자인 기준과 기존 기능 대응 정리 |
| U2 | 디자인 적용 | 홈·루틴·수행·인증·성장·랭킹·설정·관리자에 반영, 기존 서버 연결 유지 |
| U3 | 재검증·인계 | 모바일/PC·입력·승인 흐름, 자동 검사·빌드, 문서·소스 압축 갱신 |

PDF 2·4~6·9쪽의 목표-수행-인증-갱신이 1차 핵심입니다. 7쪽 관리자와 8쪽 성취·랭킹도 시제품 범위에 포함합니다. 군 공식 등급 산식, 전문가 검토된 운동 처방, 밀리패스 API 승인은 자료가 없으므로 만들어낸 값으로 운영하지 않습니다. 가상 기준에는 `demo-v1`을 명시합니다.

통증·높은 피로는 인증 대기 중에도 다음 계획을 완화할 수 있습니다. 미확인 수행을 근거로 난도를 올리지 않으며, 이미 수행된 회차와 당시 버전은 보존합니다. 인증 취소는 경험치·순위를 다시 계산하고 이력을 남깁니다.
