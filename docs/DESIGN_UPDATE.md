## 적용 방식

- 모바일 홈은 인사 → 목표 진행 → 운동 사진 → 이번 주 → 최근 인증 순서입니다. 큰 화면은 같은 요소를 넓이에 맞춰 배치합니다.
- 루틴 상세·운동 타이머·수행 결과는 현재 저장 가능한 데이터 구조에 연결합니다. 원본 시연의 클릭 즉시 승인, 고정 경험치, 고정 순위는 복사하지 않습니다.
- 성장 차트와 랭킹은 인증된 측정, 최근 인증 목록은 실제 데모 저장 기록을 표시합니다.
- 기록 유형 구분, 통증/피로 처리, 관리자 승인·보완·반려·취소, 목표·공개범위 설정을 유지합니다.
- 제공 사진을 로컬 정적 파일로 사용합니다. 사진 첨부·실제 로그인·실제 DB·배포는 이전 후속 범위입니다.

현재: U1~U3 완료. 다음 단계는 D2 실제 PostgreSQL 연결·검증입니다.

## 반영 결과

- 검정·차콜 바탕, 라임 강조, Pretendard 로컬 글꼴과 제공된 운동 사진을 적용했습니다. 모바일 하단 메뉴와 PC 사이드바를 유지합니다.
- 홈은 서버의 개인 목표·인증 측정·주간 계획·최근 인증·XP를 표시합니다.
- 루틴은 날짜 선택, 사진 카드, 운동별 세트·횟수·휴식·대체 동작을 표시합니다. 운동 화면에서 횟수 체크·일시정지·휴식·건너뛰기·중간 종료 후 실제 수행 입력으로 이어집니다.
- 성장 화면은 종목·30/90일/전체 기간, 최근 기록·변화·개인 최고 기록·차트를 제공합니다. 랭킹은 전국/지역/군단/부대와 종목을 선택합니다.
- 목표·공개 범위·컨디션·인증 폼 및 관리자 검토 화면도 같은 테마로 통일했습니다. 관리자 직접 확인·사유 입력과 기존 API 규칙을 유지합니다.
- 세트 체크는 임시 상태입니다. 제출 전에는 저장되지 않으며, 영상 재생·사진 증빙 업로드·실제 DB 연결은 포함하지 않습니다.
