# 데이터가 없을 때의 개발 및 전환 계획

## 지금

실명·군번·실제 편성 대신 ‘김도윤’, ‘러닝메이트’ 등 가상 이름/닉네임과 가상 부대를 사용합니다. 앱 전체에 데모 상태를 표시합니다. 목표·측정·수행·관리자 대기 자료를 고정된 기준으로 만들어 반복 검증합니다. 예시 경험치·랭킹은 실제 군 등급과 무관합니다.

## 나중에 받아야 할 자료

| 자료 | 최소 필드 | 확보 대상 | 사용처 |
|---|---|---|---|
| 참여자·소속 | 내부 사용자 ID, 닉네임, 소속 ID, 평가군, 권한, 랭킹 공개 동의 | 운영 담당자 | 로그인·조회 범위 |
| 조직 | 지역/군단/부대/중대/소대/분대 ID와 상위 조직 | 군 실무 담당 | 권한·집계 |
| 검토된 운동 기준 | 종목, 난도별 구성, 세트/반복/시간, 휴식, 대체 동작, 금기, 증감 상한, 버전, 검토자 | 운동기준 검토자 | 루틴 엔진 |
| 평가 기준표 | 종목, 평가군, 측정 방식, 유효 기간, 등급 경계, 시행일·출처 | 운영·전문가 | 공식 등급과 목표 |
| 초기 측정 | 사용자 ID, 종목, 값·단위, 날짜, 측정 방식, 기록 유형, 확인자 | 운영 담당 | 초기 수준·성장 |
| 목표/여건 | 목표값·목표일(선택), 가능 요일·시간, 장소·기구, 제외 일정 | 참여자 | 루틴 |
| 수행·회복 | 회차 ID, 실제 수행량, 완료 구분, RPE, 피로, 통증 여부, 확인 근거 | 참여자/관리자 | 인증·갱신 |
| 운영 정책 | 인증 절차, 공개 범위, 최소인원, 동점·정정, 보관·파기, 담당자 | 운영 책임자 | 실제 시범 |

## 전환 순서

1. 가상 시나리오로 업무 흐름과 예외를 확인합니다.
2. 운동 기준과 평가군을 확정하고 버전이 붙은 자료로 교체합니다.
3. 실제 인증 제공자와 소속/권한 연결을 검증합니다.
4. PostgreSQL을 연결하고 가상 자료와 실제 자료의 환경을 분리합니다.
5. CSV/엑셀은 별도 검증·미리보기·중복 확인 과정을 거쳐 가져옵니다. 이번 버전에는 자동 가져오기를 넣지 않습니다.
6. 소수 참여자로 인증·갱신·정정·복구를 검증한 후 참여 범위를 넓힙니다.

외부 AI 전송은 기본적으로 없습니다. 사진·위치·군번은 이번 시제품의 필수 수집 항목이 아닙니다. 수집 근거·동의·접근자·보관 기간은 실제 자료 투입 전 확정합니다. 랭킹의 ‘전국’은 전군이 아니라 플랫폼 참여자 중 조건이 같은 공개 동의자 범위입니다.
