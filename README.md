# MILIPASS FITNESS · 군학연계 체력관리

React 기반 장병 모바일 웹 + 관리자 웹 + 공통 API 시제품입니다. 원본 PDF의 목표→루틴→수행→인증→갱신→성장 흐름을 구현합니다. 공식 밀리패스 서비스나 제휴 완료 제품이 아닙니다.

소스 저장소: [Military-academic-linked-soldier-training](https://github.com/nanjinhan/Military-academic-linked-soldier-training). 기본 브랜치는 `main`입니다. 실행 결과물과 로컬 시연 데이터는 제외하며, `.env.example`을 기준으로 각 환경을 설정합니다.

**현재 완료:** F1~F4 화면, B1~B6 데모 백엔드, D1 DB 연결 준비, Q1 로컬 검증, R1 배포 준비, U1~U3 제공 폴더 디자인 반영·검증. **다음 단계:** D2 실제 PostgreSQL 연결·검증. 자동 검사 20개·타입 검사·운영 빌드를 통과했습니다. 상세 상태와 제한은 아래 진행 현황을 기준으로 합니다.

## 구현 순서

1. **P0 요구사항·설계**를 먼저 문서화합니다.
2. **F1~F4 화면**을 만들고, **B1~B6 API·업무 규칙**을 단계별로 연결합니다.
3. **D1 DB 구조·연결 코드**를 준비하되 **D2 실제 DB 연결·검증은 보류**합니다.
4. **Q1 통합 검증** 뒤 **R1 배포 준비**를 정리합니다. 실제 배포는 추후 진행합니다.

현재 수치는 모두 가상입니다. 운동량·등급표는 운영 승인을 받은 기준이 아니며, 데모의 추천은 기능 검증용입니다. 생성형 AI·밀리패스·실제 DB·실제 인증기관에 연결하지 않습니다.

## 실행

Node.js 22.13 이상을 사용합니다.

```sh
npm install
npm run dev
```

앱 주소: http://localhost:3000. 개발 실행 시 가상 사용자 체험을 선택할 수 있습니다. 가상 데이터는 `.data/demo.json`에 서버 측 저장되므로 새로고침 뒤에도 유지됩니다. 이 파일은 소스 관리에서 제외합니다.

```sh
npm run typecheck
npm test
npm run build
```

상용 배포 전에는 반드시 [배포 준비](docs/DEPLOYMENT.md)의 미완료 항목을 처리해야 합니다. 로컬 JSON 저장은 단일 프로세스 시연용이며 AWS 다중 인스턴스나 Vercel 운영 저장소로 사용하지 않습니다.
