# DB 연결 준비 상태

현재 단계는 **D1 완료, D2 미연결**입니다. DB 비밀키를 받거나 원격 DB를 만들지 않았습니다.

`001_initial.sql`은 사용자, 목표 이력, 루틴 및 버전, 수행·측정, 인증 이력, 공식 결과, 회복, XP, 감사 기록을 엔터티별 테이블로 나눕니다. 각 테이블의 payload는 공통 TypeScript 계약과 동일한 JSONB이며, 자주 검사하는 사용자/종류/상태/회차는 generated column, FK, unique constraint, index로 보호합니다. 완전히 컬럼화한 분석 스키마는 규모 확대 단계에서 분리할 수 있습니다.

초기 저장소 어댑터는 트랜잭션 advisory lock 안에서 상태를 읽고 업무 규칙을 적용한 뒤 엔터티별 upsert를 합니다. XP는 같은 트랜잭션 안에서 재계산합니다. 원본 목표·제출·인증 이력은 삭제하지 않습니다. 로컬 파일 어댑터도 같은 Repository 계약을 따릅니다.

이는 소규모 시범용 구조입니다. 실제 다수 사용자 운영 전에는 읽기 전용 조회 분리, 서버 페이지네이션, 조직별 조건 쿼리, 행 단위 잠금, 독립 XP 변경 이력 테이블을 추가해야 합니다. 현재 XP 원장은 재계산된 결과이며 원래 변경 근거는 reviews/audit에 남습니다.

실제 연결 및 검증 절차는 `docs/DEPLOYMENT.md`를 따릅니다. SQL과 PostgreSQL 어댑터는 작성·타입 검사되었지만, 아직 PostgreSQL에서 실행 검증되지 않았습니다.
